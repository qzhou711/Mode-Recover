# 行为模式发现与保模态蒸馏

> 本文档记录对ICML 2026论文《Behavioral Mode Discovery for Fine-tuning Multimodal Generative Policies》的完整理解，以及将BMD改造成跨结构、demonstration-free、mode-preserving CTM约束的方案。论文：[arXiv HTML](https://arxiv.org/html/2605.11387v1)，[项目页](https://behav-mod-dis.github.io/)。

## 1. 核心判断

BMD（Behavioral Mode Discovery）与本项目高度相关。它同样在Avoid 24-mode任务中观察到：

```text
策略原本具有多种可行路径
→ 后续优化更容易通过少数路径提高回报
→ 总体成功率提高
→ 低频、长路径或难执行模式消失
```

BMD可以帮助缓解我们的CTM mode collapse，但不能原样搬用。最值得迁移的思想是：

> 先从多步Teacher中无监督发现trajectory-level latent modes，再以mode-balanced Teacher查询、条件分布匹配和互信息约束，要求一步Student保留这些模式。

这条路线可以保持本项目的demonstration-free要求：模式发现阶段只使用Teacher rollout、环境状态和奖励，不重新访问原始示范。

需要保持审慎：BMD在论文Avoid任务上也只是缓解而非消除collapse。预训练策略覆盖20/24种模式，普通RL fine-tuning降至1–6.33种，BMD版本恢复至7.33–10种，没有恢复到20种。因此BMD是有根据的下一条方法路线，而不是直接恢复全部模式的保证。

## 2. 论文研究问题

论文研究：

> 一个已经通过模仿学习获得多模态行为的Diffusion或Flow策略，在后续RL fine-tuning提高成功率时，如何避免只保留少数reward-maximizing modes？

与本项目的关系：

| 维度 | BMD论文 | 本项目 |
|---|---|---|
| 主要过程 | RL fine-tuning | 跨结构蒸馏＋CTM步数蒸馏 |
| collapse来源 | 环境奖励偏向少数模式 | 表示迁移误差＋CTM平均损失偏置 |
| 优化起点 | 完整预训练模型 | Teacher-derived有限容量Student |
| 主要优化对象 | Steering、Residual或主策略 | 一步Flow Student |
| 数据假设 | 预训练时有示范，fine-tuning时在线交互 | 最终不访问原始示范 |
| 目标 | 保留RLFT前的模式 | 保留Teacher或Repair起点的模式 |

二者虽然优化过程不同，但结构相同：后续优化目标对模式频率不敏感，最容易通过集中概率质量到少数高回报、低误差或短路径模式改善平均指标。论文指出Avoid的路径长度不对称会使fine-tuning偏向短路径，这与当前CTM偏向少数闭环安全路径的现象一致。

## 3. BMD方法

### 3.1 从噪声到行为模式

噪声条件生成策略写作：

```text
a ~ πθ(a | s, w)
```

其中`s`是状态，`w`是Diffusion或Flow输入噪声，`a`是生成动作。若不同噪声产生不同动作分布，则：

```text
I(W; A | S) > 0
```

论文给出：

```text
I(W; A | S)
= E_s,w [ KL(πθ(·|s,w) || p(·|s)) ]
```

但action-level diversity不等于behavioral diversity。不同关节动作可能经过环境动力学后形成同一条任务轨迹。因此论文使用噪声与visited states或trajectory之间的互信息：

```text
I(W; trajectory states)
```

由`W → A → S'`和数据处理不等式可知，state-level互信息是更保守的多模态指标，只保留真正传播到闭环轨迹的动作差异。

这对本项目的直接启示是：当前Endpoint Gram只比较一步动作输出几何，它可能把局部动作差异误认为模式，也无法保证差异在环境动力学中持续。模式约束应逐渐从action endpoint提升到short-horizon和closed-loop trajectory层面。

### 3.2 离散行为变量

原始噪声`w`连续、局部且可在每个控制时刻改变，难以对应完整轨迹模式。BMD引入episode级离散变量：

```text
z ∈ {1, ..., K}
```

并学习Steering Policy：

```text
w_t ~ πψ(w | s_t, z)
```

由此得到：

```text
πθ,ψ(a | s,z)
= ∫ πθ(a | s,w) πψ(w | s,z) dw
```

同一`z`在完整episode中固定，使其能够表达连贯的trajectory-level behavior。论文使用`K∈{4,8,16}`，不要求知道真实模式数；无监督发现的`z`也不必与人工模式一一对应。

### 3.3 Inference Model与互信息下界

BMD训练一个分类器：

```text
qφ(z | s)
```

具体实现中也使用状态和动作信息。若给定`z`产生稳定且可区分的轨迹，分类器应能从visited state或trajectory推断`z`。

互信息的变分下界为：

```text
I(Z; S)
>= E[log qφ(z | s) - log p(z)]
```

当`p(z)`均匀时，最大化该下界鼓励：

- 每个`z`都被使用；
- 不同`z`产生可区分轨迹；
- 同一`z`产生相对一致行为。

它与DIAYN等无监督skill discovery形式相似，但目的不同：BMD不是从零发现任意技能，而是组织冻结的预训练生成策略已经编码的行为。

### 3.4 两阶段训练与curriculum

第一阶段只使用互信息内在奖励：

```text
r_int
= λ [log qφ(z | s_next) - log p(z)]
```

目的是先建立稳定的`z→trajectory mode`映射。

第二阶段加入环境奖励：

```text
r_total
= r_env + r_int
```

论文还使用short-to-long horizon curriculum。先学习短期可辨识行为，再逐渐延长到完整episode，避免Steering Policy和Inference Model一开始就联合解决长时序一致性问题。优化采用PPO，但作者认为互信息框架不依赖特定RL算法。

## 4. 论文实验结论

### 4.1 Avoid结果

论文Avoid任务结果：

| 方法 | SR | Mode coverage | 熵 |
|---|---:|---:|---:|
| 预训练策略 | 0.94 | 20/24 | 0.63 |
| Residual FT | 0.98 | 1/24 | 0.00 |
| Steering FT | 1.00 | 2/24 | 0.01 |
| DPPO | 1.00 | 6.33/24 | 0.13 |
| Residual＋BMD | 0.99 | 7.33/24 | 0.53 |
| Steering＋BMD | 1.00 | **10/24** | **0.58** |
| DPPO＋BMD | 0.94 | 9.67/24 | 0.57 |

BMD显著提高覆盖和熵，但没有恢复预训练模型的20种模式。

论文coverage与本项目定义不同。论文使用`mc@0.80`：某mode的独立成功率达到0.8才计为覆盖；本项目当前coverage是成功轨迹中是否出现该模式。因此绝对数值不能直接横向比较，只能比较collapse趋势和方法相对收益。

### 4.2 动作熵不能代替轨迹多样性

论文在ANYmal对比普通policy entropy、RND与BMD。普通entropy bonus仍可能只产生一种trajectory mode；BMD可以恢复更多模式。这说明：

```text
高action entropy
≠ 高trajectory diversity
```

本项目不应只增加一步动作方差或输出间距离，而应约束：

```text
noise或latent identity
→ 多步闭环轨迹
```

### 4.3 BMD自身的局限

论文和附录显示：

- 多个`z`可能最终对应同一环境mode；
- 小状态扰动可能让分类器将同一真实mode视为不同；
- 不同seed可发现相似mode集合，但`z`编号存在置换对称；
- latent数量`K`是超参数，不等于真实模式数；
- 互信息权重过大时成功率下降；
- 环境分布变化后若不继续更新Steering和Inference Model，互信息信号会失效；
- 严重动力学变化会使底层预训练策略本身失效，此时BMD无法凭空恢复模式。

因此，最大化Student自己的互信息不自动等于保存Teacher模式。Student和分类器还可能共同形成容易分类但没有任务意义的伪多样性。

## 5. 为什么不能直接套用BMD

原版BMD需要：

1. Steering Policy；
2. Inference Model；
3. PPO和大量环境rollout；
4. 在CTM后进行RL fine-tuning或通过Steering间接改变行为。

直接套用会带来：

- 研究问题变成“CTM后RL修复”，而不是“CTM过程中保模态”；
- 需要环境奖励和大量在线交互；
- Steering可能发现Student的新模式，而非保留Teacher模式；
- Student自己的互信息可能通过无效或OOD行为提高；
- 无法保证Teacher的noise→mode语义得到保留。

因此第一步不应直接完整复现PPO版BMD，而应改造成Teacher-relative BMD distillation。

## 6. Teacher-relative BMD

### 6.1 模式发现对象

第一阶段建议冻结Velocity-250的16步Student并将其作为mode source，而不是立即使用4×72大Teacher。

当前需要精确解释：

```text
Velocity-250 Repair：22 modes
→ 一步CTM：8 modes
```

在Repair起点发现模式，可以直接测量步数蒸馏保留了多少输入模式：

```text
冻结 FM-3x48-16 Velocity-250
学习 πψ_T(w | s,z)
学习 qφ_T(z | trajectory)
最大化 I(Z; trajectory)
```

该过程只需要冻结Repair模型、环境rollout、状态、动作与成功信号，不访问原始示范，仍属于：

```text
demonstration_free: true
teacher_rollout_and_environment_required: true
```

后续可用4×72 Teacher重复，判断结构Repair前后的BMD latent支持是否已经发生变化。

### 6.2 BMD-balanced Teacher buffer

发现`z`后，对每个`z`等量采样Teacher轨迹：

```text
B_z
= {(state, noise, teacher trajectory, endpoint)}
```

CTM batch对不同`z`分层等量采样。这把当前依赖人工mode标签的mode-balanced思路改造成无需标签、可迁移的BMD-balanced buffer。

这是最优先的实验，因为它直接检验：

> 当前collapse有多少来自不同latent behavior在CTM batch和梯度中的频率不均衡？

它也最容易迁移到WAM，因为不依赖24种路径定义或特定网络内部层。

### 6.3 条件分布匹配

普通CTM目标扩展为：

```text
L_total
= L_CTM
 + α L_DSM
 + β L_mode-fidelity
 + γ L_MI
```

对同一个`z`要求Student和Teacher条件轨迹分布接近：

```text
L_mode-fidelity
= Σ_z D(
    p_student(trajectory | z),
    p_teacher(trajectory | z)
  )
```

距离`D`可逐级比较：

- endpoint MMD；
- short-horizon trajectory embedding MMD；
- energy distance；
- sliced Wasserstein；
- Teacher/Student条件均值和协方差匹配。

这比当前全局centered-Gram更强，因为全局Gram不知道哪些样本属于同一行为族，容易只保存总体输出离散程度而丢失条件mode identity。

### 6.4 Teacher-frozen互信息约束

冻结在Teacher上学到的Inference Model：

```text
qφ_T(z | trajectory)
```

要求Student轨迹仍能被识别为对应`z`：

```text
L_MI
= -E[log qφ_T(z | trajectory_student)]
```

均匀`p(z)`下，`-log p(z)`是常数，训练时可省略。

优先冻结Teacher classifier，避免Student与分类器共同漂移或“串通”出与Teacher无关的伪模式。后续如需适应Student-induced states，可使用慢速EMA或teacher-anchored更新，而不是完全自由联合训练。

### 6.5 任务有效性约束

互信息可以奖励互相不同但失败的轨迹，因此还需要：

- 只使用Teacher成功rollout建立mode buffer；
- 环境成功奖励或可学习的成功critic；
- per-latent success下界；
- Student-induced states上的Teacher校正；
- Teacher endpoint/trajectory fidelity。

最终交集是：

```text
保留Teacher模式
∩ 每种模式闭环有效
∩ 一步Student可执行
```

而不是单纯提高输出差异。

## 7. 三个递进实验

### 实验A：BMD-balanced buffer

1. 冻结Velocity-250；
2. 学习BMD latent `z`；
3. 按`z`均衡生成Teacher buffer；
4. 使用原始CTM，不增加新loss；
5. 比较是否从当前8种恢复更多模式。

优点：因果最清楚、实现风险最低、保持demonstration-free、最容易迁移到WAM。

### 实验B：BMD classifier regularization

在A上加入：

```text
L_MI = -log q_T(z | student trajectory)
```

它检验在数据已均衡后，是否仍需显式保持trajectory-level mode identity。

D3IL环境未必适合对完整闭环轨迹反向传播，因此可分两步：

1. 先使用`q_T(z | short action chunk / predicted endpoint)`；
2. 再采用post-CTM PPO或可学习dynamics model实现长轨迹互信息。

### 实验C：BMD conditional distribution matching

对每个`z`分别匹配Teacher和Student的样本集合分布。这一版本不一定需要环境反向传播，只需Teacher rollout和离线trajectory embedding。

它比单纯MI更符合最终目标，因为约束的是Teacher-relative conditional distribution，而不是Student自身的可分类性。

## 8. 公平实验矩阵

固定：

- Velocity-250 Repair起点；
- 3×48 Student；
- 500 CTM epochs；
- 相同buffer总量；
- 相同Teacher-query预算；
- 不访问原始示范；
- 100/250/500 checkpoint。

| 实验 | Buffer | 新约束 | 定位 |
|---|---|---|---|
| CTM baseline | 普通Teacher rollout | 无 | 当前基线 |
| CTM＋人工mode-balanced | 人工mode均衡 | 无 | D3IL诊断上界 |
| CTM＋BMD-balanced | 无监督`z`均衡 | 无 | 数据频率因素 |
| CTM＋BMD-MI | BMD均衡 | Teacher classifier | mode identity |
| CTM＋BMD-distribution | BMD均衡 | per-z分布匹配 | 条件分布保持 |
| CTM＋BMD-MI＋distribution | BMD均衡 | 两者组合 | 完整候选 |

人工mode-balanced只作为D3IL oracle，不属于最终可迁移方法。

评价必须包括：

- Standard-120筛选、Standard-480确认；
- Paired-1000/JS；
- Coverage与归一化熵；
- 每个BMD latent的成功率；
- `z→真实mode`混淆矩阵；
- NMI与ARI；
- 一个`z`是否映射多个真实mode；
- 多个`z`是否坍缩为同一真实mode；
- 至少3个seed。

## 9. 验收与决策

### 阶段一：BMD发现质量

最低要求：

- 多个`z`产生可区分且成功的轨迹；
- `q_T`在held-out Teacher rollout上有显著高于随机的分类准确率；
- `z→真实mode`不是全部集中到少数模式；
- 多seed的mode集合具有较高NMI/ARI，允许latent编号置换。

若BMD在Velocity-250上只能发现少数模式，应先扩大Teacher-query和优化horizon curriculum，不进入CTM。

### 阶段二：CTM收益

第一目标不是立即恢复22种，而是在相同Teacher-query预算和SR下显著超过普通CTM的8种模式。候选通过Standard-120后必须补Standard-480和多seed。

只有BMD-balanced有效：说明主要收益来自训练分布均衡。

BMD-balanced无效、MI或distribution有效：说明CTM目标本身需要显式保持mode identity。

所有版本均无效：检查一步Student可表达性、latent发现质量和trajectory encoder；不能直接得出BMD思想无效。

## 10. 对跨架构WAM的意义

BMD不要求：

- Teacher与Student层数相同；
- attention head一一对应；
- 已知24种人工模式；
- 显式动作概率密度。

它只依赖：

```text
latent/noise
→ 生成策略
→ world-action trajectory
```

因此比MiniLMv2 relation更接近可迁移的通用约束。在WAM中Inference Model可扩展为：

```text
q(z | future-world embedding, action trajectory)
```

分别约束：

- Action mode可辨识；
- Future-world mode可辨识；
- world与action对应同一`z`；
- Student每个`z`与Teacher相应条件分布对齐。

必须防止WAM仅通过改变无关视频纹理提高互信息，而动作行为没有真正多样。建议拆分：

```text
I(Z; action trajectory)
I(Z; task-relevant world state)
world-action consistency
```

不能只最大化视频embedding的可分性。

## 11. 最终判断

| 判断项 | 结论 |
|---|---|
| 与本项目相关性 | 非常高 |
| 原版BMD直接复用 | 中低可行性，需要PPO、Steering和大量rollout |
| Teacher-relative BMD | 高可行性 |
| 最优先组件 | BMD发现＋无监督mode-balanced Teacher buffer |
| 最有论文价值组件 | per-mode conditional distribution matching＋Teacher-frozen MI |
| 完全恢复22种模式 | 不能保证，原论文也只部分恢复 |

BMD给本项目带来的核心变化是：

> 不再用单步动作距离或全局Gram近似mode，而是把Teacher噪声组织为trajectory-level latent behaviors，再逐mode完成跨结构、跨步数分布蒸馏。

这比继续增大Endpoint或Gram权重更有理论和实验依据，也更符合未来DreamZero等WAM跨架构蒸馏的可迁移目标。

## 20. 闭环Teacher Replay与首次通过短期门槛（2026-07-31）

### 20.1 审计与方法

旧Student-induced门控会覆盖223条Teacher、Student均成功的轨迹，并锚定约51条
双失败轨迹。修正门控虽然提高SR，但Standard-120最高覆盖仅11/24，说明只保护
Student已有成功行为不能恢复缺失模式。

进一步审计发现：

- 成功Teacher replay含80,077个step、24/24无标签latent和23/24真实mode；
- Student在24个latent上的Teacher endpoint误差均匀且非零；
- Teacher replay与失败修正梯度同向，但与成功Student锚定在训练后冲突；
- 全部数据来自Teacher/Student真实闭环rollout，不访问原始示范或专家动作。

Balanced Replay采用三级均匀采样：

```text
latent -> Teacher成功episode -> episode内timestep
```

Natural Replay则在所有成功Teacher step中自然采样。另设成功Student anchor和
PCGrad式冲突投影消融。

### 20.2 预注册checkpoint选择

四种方法先评估epoch 50/100/250的Standard-120。每种方法按预先固定规则选择一个
checkpoint：`SR>=60%`后，依次最大化覆盖、SR、熵。选中结果为Natural-100、
Balanced-50、Balanced＋Anchor-100、Balanced＋Anchor＋PCGrad-50。

### 20.3 Standard-480结果

| 方法 | Checkpoint | SR | 成功mode覆盖 | 模式熵 | 达到65%/18门槛 |
|---|---:|---:|---:|---:|---:|
| **Natural Replay** | 100 | **328/480，68.3%** | **20/24** | 0.741 | **是** |
| Balanced Replay | 50 | 312/480，65.0% | 19/24 | **0.752** | **是** |
| Balanced＋Anchor | 100 | 308/480，64.2% | **20/24** | 0.693 | 否 |
| Balanced＋Anchor＋PCGrad | 50 | 316/480，65.8% | 18/24 | 0.645 | **是** |

### 20.4 结论

1. 无示范Teacher成功轨迹replay首次让一步Student明确达到短期目标；缺失模式可以从
   Teacher闭环分布重新注入，而非只能保护Student已有模式。
2. Natural Replay给出当前最佳Pareto，说明自然频率可能包含任务难度信息；强制均衡
   提高熵，但没有提高覆盖或SR。
3. 成功Student anchor降低SR和熵；PCGrad虽缓解梯度冲突，但仍被更简单的Natural
   Replay支配，暂不继续调参。
4. Standard-120将Natural覆盖估为16，而Standard-480为20；120只能粗筛，不能支持
   精细覆盖claim。
5. 当前结果仍是单训练seed。下一步固定Natural epoch 100和Balanced epoch 50，各补
   seed 43/44并直接Standard-480；不得在新seed上重新挑checkpoint。


Natural三个seed均达到`SR>=65%、Coverage>=18`，稳定完成当前步数蒸馏短期目标。
Balanced提高熵，但SR均值低且seed敏感，因此降级为频率均衡消融。

### 21.2 Solver-only诊断

对同一个Natural一步checkpoint直接改变推理solver调用次数：

| Solver步数 | SR | 覆盖 | 熵 |
|---:|---:|---:|---:|
| 1 | 68.3% | 20/24 | 0.741 |
| 2 | 52.3% | 17/24 | 0.693 |
| 4 | 40.6% | 18/24 | 0.725 |
| 8 | 38.3% | 19/24 | 0.804 |

一步boundary map被重复调用后进入未训练的中间状态分布，SR随步数增加而下降。因此
“直接多调用solver”不能恢复准确率。该结果不代表重新训练的2步/4步Student也会
变差；后者必须单独训练后才能判断。

### 21.3 强4x72 Teacher小buffer初探

现成强Teacher buffer含240条无示范rollout、14,641个成功step，Teacher
`SR=96.7%`、覆盖23 modes。直接对已有3x48一步Student进行Natural Replay：

| Checkpoint | Standard-120 SR | 覆盖 |
|---:|---:|---:|
| 50 | 59.2% | 9/24 |
| 100 | 60.8% | 12/24 |
| 250 | 64.2% | 9/24 |

按预注册规则选择epoch 100，其Standard-480为：

```text
SR 63.3%，Coverage 14/24，H 0.583
```

该负结果不能解释为强Teacher较差，因为同时存在两项混杂：强Teacher数据只有240条，
而Velocity-250扩展buffer有2400条；此外实验同时改变Teacher来源并直接压缩结构与
步数。它支持下一阶段先扩大强Teacher buffer，再将结构蒸馏与步数蒸馏严格拆开。

### 21.4 阶段结论

1. Natural Replay是当前稳定的demonstration-free保模态步数蒸馏基线；
2. 当前约96%到约67%的主要SR差距不应归因于Natural Replay，而要回到
   `4x72->3x48-16`结构迁移阶段处理；
3. BMD式无标签mode只用于轨迹审计、覆盖统计和必要的采样消融，不再直接作为冻结
   分类器交叉熵梯度；
4. 后续必须报告每个阶段的独立retention，禁止用一个端到端数字混淆结构损失与
   步数损失。
