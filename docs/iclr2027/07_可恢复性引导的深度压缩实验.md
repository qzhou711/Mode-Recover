# 可恢复性引导的深度压缩实验

更新时间：2026-08-01

## 1. 实验动机

TinySR指出，扩散Transformer的剪枝结构不应只根据静态重要性、输入输出相似度或剪枝瞬间的
loss选择，而应根据候选结构经过有限恢复训练后的任务性能，即recoverability选择。论文使用
概率mask、Dynamic Inter-block Activation与Expansion-Corrosion处理深层网络的组合爆炸。

当前Avoid Flow Matching Teacher只有4层，因此本实验没有照搬Gumbel mask搜索，而是穷举
全部四种保留3层的有序子集。这样能无近似地回答：哪一层最可删除、哪一种浅层结构最容易从
Teacher rollout中恢复闭环能力？

参考论文：`papers/TinySR_CVPR2026.pdf`。

## 2. 研究问题与目标关系

长期目标是实现demo-free、可迁移到FastWAM/DreamZero的跨结构与跨步数机器人生成策略蒸馏，
同时保持mode diversity。本实验只研究结构蒸馏的深度维度：

```text
FM-4x72-16 Full Teacher
  -> FM-3x72-16 depth-only Student
```

它不改变hidden width、attention heads和solver steps，因此不会把深度压缩、宽度压缩与步数
压缩混在一起。若该阶段成功，下一阶段才固定最佳深度mask并执行`3x72 -> 3x48`宽度压缩。

## 3. 审计后的统一协议

### 3.1 模型与初始化

| 项目 | 设置 |
|---|---|
| Teacher | `FM-4x72-16-Full`，274,826参数 |
| Student | `FM-3x72-16`，211,682参数 |
| 参数减少 | 63,144，约22.98% |
| 候选mask | keep012、keep013、keep023、keep123 |
| 初始化 | 共享模块及所选Teacher block逐元素复制 |
| 初始化审计 | 所有候选`max_abs_diff=0` |

`keep013`表示Student的三层依次复制Teacher的零索引第0、1、3层，即删除Teacher的第2层。

### 3.2 数据与训练

- 使用`strong_teacher_expanded_2400`中的成功Teacher rollout；
- 训练样本146,666个状态窗口；
- 不读取原始demonstration，不使用专家动作；
- 四组共用相同buffer、seed 42、batch顺序、优化器和scheduler；
- AdamW，学习率`3e-5`，500 epochs，每epoch最多4 batches；
- 目标为Teacher velocity MSE加弱endpoint anchor，`lambda_endpoint=0.03`；
- 保存epoch 50、100、250、500。

这一训练目标不是TinySR的LPIPS/GAN复刻：图像任务可以访问原始LR/HR配对，而本实验保持
demo-free，只使用Teacher生成监督。迁移的是“按恢复后任务性能选结构”的原则。

### 3.3 评估与预注册选择

- 每个checkpoint先做单GPU四worker Standard-120；
- 门槛为`SR>=80%`且成功轨迹覆盖`>=22/24`；
- 通过者按SR、覆盖、模式熵排序；
- 选中候选补Standard-480；
- 覆盖和熵只在成功轨迹上计算，不能替代逐mode成功率；
- Standard-120只作筛选，不用于1--3个mode的论文级细粒度结论。

审计文件：`logs/avoiding/tinysr_depth_recoverability/audit.json`。

## 6. 机制分析

### 6.1 这项结果证明了什么

1. **强Teacher知识可以在demo-free条件下完成高质量纯深度迁移。** 91.0%/24显著超过此前
   直接`4x72 -> 3x48`的约60%/22。
2. **此前主要问题不是Teacher rollout不可用。** 相同强Teacher buffer在合理浅层结构上可以
   恢复接近Teacher的闭环性能。
3. **同时压缩深度和宽度是主要混杂。** 旧Early-layer不仅删除层，还把72维投影到48维；本次
   保持72维后性能大幅恢复。
4. **层选择必须看恢复后闭环性能。** keep013与其它组合差距巨大，静态复制early layers不是
   普遍安全规则。
5. **层具有功能不对称性。** 删除第0层最有害；删除第1层也明显损害恢复；删除最后一层比删除
   第2层更差。当前Teacher的第2层最可恢复。

### 6.2 尚未证明什么

1. 目前只有一个训练seed，尚不能声明跨seed稳定；
2. Standard-480包含用于筛选的前120条episode，存在轻微选择重叠，需要独立episode suite；
3. 24/24中最少mode只有3条成功，需逐mode SR和多seed确认尾部稳定性；
4. 尚未测量实际延迟和MAC，参数减少23%不能直接等同于23% wall-clock加速；
5. 当前仍为16步，没有验证步数蒸馏；
6. 4层网络可以穷举，尚未验证TinySR概率mask机制在深层WAM上的有效性；
7. 结果不能说明`3x48`容量不足，因为`FM-3x48-16-Full`已达到92.7%/24；真正未解决的是
   demo-free宽度知识迁移。

## 7. 后续实验基线与执行顺序

### P0：固定深度结论

- [ ] keep013 epoch-500补训练seed 43/44；
- [ ] 使用不与Standard-120重叠的独立480条episode确认；
- [ ] 输出逐mode频次、逐mode SR、参数量、MAC和实测延迟；
- [ ] 若独立评估仍约`SR>=88%、Coverage>=22`，正式固定keep013。

### P1：单独解决宽度压缩

固定`FM-3x72-16 keep013`为新Teacher，执行`3x72 -> 3x48`，不再改变深度mask、heads以外的
必要维度或solver steps。四卡优先比较：

1. activation-aware/PCA width projection＋统一Repair；
2. MiniLMv2 Q/K/V relation width transfer；
3. Teacher Assistant：`3x72 -> 3x60 -> 3x48`；
4. recoverability-guided width channel/subspace选择。

共同门槛为`Standard-120 SR>=80%、Coverage>=22`，通过者补独立Standard-480。必须同时报告
相对3x72 Teacher的SR retention、mode retention和熵变化。

### P2：完整结构蒸馏与步数蒸馏

只有3x48-16通过结构门槛后，才执行Natural Replay或保模态CTM的`16 -> 1`步数蒸馏，分别
报告深度、宽度和步数三阶段损失。不得直接从4x72联合压缩到3x48-1后再反推原因。

### P3：深层WAM迁移

在D3IL确认recoverability criterion后，FastWAM/DreamZero等深层Transformer才需要
TinySR式blockwise probability、Dynamic Inter-block Activation与Expansion-Corrosion。
WAM的mask选择目标必须加入动作闭环成功、条件多样性和world-action一致性，不能只复用图像
LPIPS/L1。
