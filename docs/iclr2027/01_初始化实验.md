# Teacher-derived初始化实验

## 1. 文档边界

本文件只记录student开始Repair前的权重构造，以及初始化对后续实验的控制作用。若方法包含velocity、endpoint、关系或轨迹损失更新，应归入Repair文档。

## 2. 初始化方法

| 初始化 | 核心做法 | 是否需要原始示范 |
|---|---|---|
| Random | 随机创建student | 否 |
| Teacher-init | teacher/student同结构时逐参数复制 | 否 |
| Full-student warm start | 使用原始数据完整训练的同结构student | 是 |
| Structured/Early-layer | 选择teacher层、head和通道并投影 | 否 |
| Activation-aware | 用teacher buffer激活能量选择子空间 | 否 |
| PCA/SVD | 用calibration activation构造连续低秩基底 | 否 |
| Width-only | 保留4层，仅将72维压至48维 | 否 |
| Teacher Assistant | 先迁移到4×48，再映射到3×48 | 否；但其训练属于Repair |

## 3. 初始化错误纠正

旧`FM-3x48-1-Distill-3x48`曾因显式构造student而实际使用Random-init；它的76.9%/11模式/H=0.122是有效随机初始化消融，但不能证明`3×48`天然容易collapse。

正确同规模Teacher-init结果为92.1%/23模式/H=0.868。初始化必须显式记录，并验证加载后的逐参数最大绝对差为0。

## 4. Full-student warm start容量扫描

固定teacher为`FM-4x72-16-Full`：

| Student | Full-16 | Solver-1 | Full-init Distill-1 |
|---|---|---|---|
| `2×36` | 66.5% / 24 / 0.942 | 55.8% / 16 / 0.700 | 71.9% / 17 / 0.775 |
| `3×48` | 92.7% / 24 / 0.965 | 82.1% / 14 / 0.569 | 88.8% / 23 / 0.832 |
| `4×64` | 93.8% / 24 / 0.934 | 48.1% / 13 / 0.586 | 94.0% / 23 / 0.879 |

控制初始化后，容量越大，跨规模一步蒸馏的SR与多样性总体越高；但Random-init造成的严重collapse不能简单归因于容量。

## 5. Teacher-derived初始化的纯初始化验收

`FM-4x72→3x48` Early-layer纯初始化、16步Standard-120只有：

| 方法 | SR | 覆盖 | 熵 |
|---|---:|---:|---:|
| Early-layer，仅初始化 | 3.3% | 1/24 | 0.000 |

这说明权重投影本身不足以完成结构迁移，必须经过teacher-only Repair。旧五损失repair使用原始状态和专家动作，不满足目标假设，已降级为机制消融。

## 6. 初始化方法的当前判断

- Full-student warm start是强上界，但依赖原始数据，不是最终方案；
- Random-init是必要下界；
- Early/Activation/PCA/Width只应作为Repair起点，不能用Repair后结果反推纯初始化质量；
- Teacher Assistant的优势来自中间模型训练，不应被描述成零成本初始化；
- 初始化必须同时用开环端点误差、关系保持和初始化后16步闭环结果验收。

## 7. 作废或降级结论

- 作废：`3×48`同规模蒸馏天然容易collapse；
- 作废：旧容量扫描已经排除初始化影响；
- 降级：Teacher-derived投影后高SR可证明初始化优秀；高SR可能来自后续Repair；
- 保留：初始化决定了后续可达到的SR—多样性Pareto区域。

## 8. 待补实验

1. 为PCA、Activation、Early和Width保存统一的“初始化后、Repair前”开环指标；
2. 在teacher-only前提下比较同一Repair对不同初始化的敏感性；
3. 对Teacher Assistant分别验收4×48中间模型和3×48最终模型；
4. 避免把原始数据训练的Full-student warm start作为现实可用方案。
