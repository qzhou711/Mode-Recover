# Flow Matching跨规模蒸馏方法、Consistency Distillation关系与实验汇总

## 1. 研究目标与统一记号

目标是在机器人Flow Matching policy中同时压缩模型规模与推理步数，并研究蒸馏后的成功率和mode collapse。当前核心设置是：

- teacher：`FM-4x72-16-Full`，274,826参数，16步Heun；
- student：主要为`FM-3x48-1`，95,042参数，一步推理；
- Full-student初始化：`FM-3x48-16-Full`；
- Avoiding任务共有24种轨迹模式；
- 本文新增实验均先用`Standard-120`筛选，不能替代论文级`Standard-480/Paired-1000`。

记号：

```text
T, S              teacher与student
x_t               Flow时间t的动作变量；t=0为噪声，t=1为数据
v_T, v_S          teacher与student速度预测
Phi_T(x,t->1)     teacher从t到1的多步ODE积分终点
G_S(x,t,s)        student从t到s的一步映射
S_ema             student的EMA target network
```

## 2. 已使用的方法及公式

### 2.1 Pointwise velocity distillation

```text
L_point = ||v_S(x_t,t,state) - v_T(x_t,t,state)||^2
```

逐点拟合teacher局部速度场，计算较便宜。局部速度相似不保证一步终点、闭环成功率或路径模式一致。

### 2.2 Teacher endpoint / shortcut distillation

```text
y_T = Phi_T(x_t,t->1)
y_S = x_t + (1-t) v_S(x_t,t,state)
L_endpoint = ||y_S-y_T||^2
```

teacher完整多步积分产生固定终点，student直接学习一步到达。监督强且不依赖student自举；代价是训练时需要运行完整teacher。

### 2.3 简化EMA endpoint consistency

```text
x_u      = TeacherStep(x_t,t->u)
y_online = Endpoint_S(x_t,t)
y_target = Endpoint_S_ema(x_u,u)
L_simple-CD = Huber(y_online,y_target)
```

teacher只推进相邻小步，EMA student提供终点target。它包含Consistency Distillation的相邻teacher步和EMA自举思想，但没有学习任意`t->s`映射，因此不是完整CTM。

### 2.4 原始残差式Flow-CTM

```text
G_S(x,t,s) = x + (s-t) v_S(x,t,s)

y_s = G_S(x_t,t,s)
z_s = G_S_ema(x_u,u,s)

L_CTM = Huber(
    G_S_ema(y_s,s,1),
    G_S_ema(z_s,s,1)
)
```

它学习任意`t->s`转换，训练图比简化CD更接近CTM；但用单步Euler残差表达长跨度转换，缺少官方式边界预条件。

### 2.5 Boundary-CTM

Flow时间方向是噪声`0`到数据`1`。定义：

```text
r = (1-s)/(1-t)
F_S(x,t,s) = x + (1-t) v_S(x,t,s)
G_S(x,t,s) = r x + (1-r) F_S(x,t,s)
```

严格满足：

```text
G_S(x,t,t) = x
G_S(x,t,1) = F_S(x,t,1)
```

CTM loss仍使用上一节的双路径和末端空间pseudo-Huber。Boundary参数化修正的是映射边界，不直接保证不同噪声对应不同模式。

### 2.6 DSM辅助损失

```text
x_t = (1-t) noise + t action
L_DSM = Huber(G_S(x_t,t,1), action)
L_total = alpha L_CTM + beta L_DSM
```

DSM使student持续接触原始专家动作，抑制纯EMA自举的漂移。DSM不是CD本身，而是官方Consistency Policy与CTM联合使用的辅助数据目标。

### 2.7 Boundary-CTM加teacher endpoint anchor

```text
L_anchor = Huber(
    G_S(noise,0,1),
    Phi_T(noise,0->1)
)

L = L_CTM + beta L_DSM + lambda L_anchor
```

EMA一致性负责跨时间学习，固定teacher终点尝试限制自举漂移。本项目测试了`lambda=0.05/0.1`。

### 2.8 双锚定蒸馏

```text
L = L_large-teacher-shortcut
  + lambda ||y_S-y_FullSmall||^2
```

同时对齐大teacher与完整训练的小模型。提高小模型锚定权重通常增加模式覆盖，但会牺牲从大teacher获得的成功率。

### 2.9 多噪声分布/几何蒸馏

```text
L_dist = distance(D(Y_S),D(Y_T))

D = pairwise distance / centered Gram / Sinkhorn
```

同一状态采多个噪声，匹配student和teacher输出集合的欧氏几何。现有Pairwise、Gram、Sinkhorn版本均未稳定保护Avoiding闭环路径模式；动作空间距离不等价于绕障路径拓扑。

### 2.10 DDIL / student-induced state distillation

```text
x_t^S = student自己产生的中间状态
L_DDIL = ||v_S(x_t^S,t)-v_T(x_t^S,t)||^2
```

teacher在student会访问的偏移状态上重新标注，可改善闭环自洽性和成功率；当前版本容易强化少数安全模式，不能单独承担mode preservation。

## 3. Boundary-CTM、DSM与Consistency Distillation的关系

概念层级为：

```text
Consistency Distillation
└── CTM：学习任意t->s的一致映射
    ├── Boundary参数化：严格满足G(x,t,t)=x
    └── DSM：保留原始数据生成能力的辅助损失
```

因此：

- Boundary-CTM是当前CD核心；
- DSM不是CD本身，而是与CTM联合训练的稳定项；
- `Boundary-CTM + DSM`是本项目中最接近官方Consistency Policy训练图的实现；
- `Boundary-CTM + DSM + endpoint anchor`是本项目扩展，不是官方基础目标。

官方EDM时间从高噪声`t`走向低噪声`s`，本项目Flow时间方向相反。二者的训练图对应为：

```text
官方：
x_t --online t->s--> y_s --EMA s->0--> y_0
x_t --teacher t->u--> x_u --EMA u->s--> z_s --EMA s->0--> z_0

本项目：
x_t --online t->s--> y_s --EMA s->1--> y_1
x_t --teacher t->u--> x_u --EMA u->s--> z_s --EMA s->1--> z_1
```

两者均在完全去噪/最终动作空间计算pseudo-Huber，只允许online `t->s`分支更新；teacher和EMA参数冻结，但online路径经过EMA末段映射时保留对输入的梯度。

与官方实现仍有差异：

1. 官方使用EDM噪声过程，本项目使用线性Flow路径；
2. 官方网络分别编码并拼接`t、s`，本项目复用Transformer时间嵌入并组合目标时间；
3. 官方使用EDM的`c_skip/c_out/c_in`，本项目使用Flow方向的`r=(1-s)/(1-t)`；
4. 因而当前实现应称为Flow-adapted Boundary-CTM，而非官方逐行复现。

### 3.1 术语更正：boundary不是独立的新方法

标准Consistency Model/CD本来就应包含边界条件。“Boundary-CTM”不是一种独立于CTM的新算法，而是本项目为了区分两版Flow实现采用的临时名称。

```text
标准CD：f_theta(x_t,t) -> x_data
CTM：G_theta(x_t,t,s) -> x_s
```

二者分别满足固定数据边界条件和双时间恒等边界`G_theta(x,t,t)=x`。本项目早期版本使用`G=x+(s-t)v_theta`，当前版本改用端点插值预条件。因此更准确的命名是：

```text
早期版本：Residual Flow-CTM approximation
当前版本：Flow-CTM (boundary-preconditioned)
```

不应使用“Boundary-CTM”暗示普通CD或规范CTM没有boundary condition。本文保留旧实验目录名用于追溯，但方法含义统一按上述更正理解。

### 3.2 标准CD是否支持anytime-to-anytime

原始Consistency Model/CD通常学习从任意噪声时间到固定数据边界：

```text
f_theta(x_t,t) -> x_data
```

模型不显式接收目标时间`s`，因此通常不是anytime-to-anytime。CTM增加目标时间条件：

```text
G_theta(x_t,t,s) -> x_s
```

才显式支持任意`t->s`。可以通过组合、重参数化或特定Consistency方法构造其他时间转换，但这不等于原始CD网络本身就是显式双时间映射。

### 3.3 标准CD不是纯fidelity distillation

不能把标准CD简单归类为“fidelity distillation，而不是trajectory distillation”。标准CD的监督仍来自teacher ODE轨迹相邻点：

```text
x_t --teacher ODE--> x_u
f_theta(x_t,t) ~= f_ema(x_u,u)
```

它使用teacher trajectory信息，只是输出始终指向同一个数据终点，而不直接预测任意目标时间。

| 方法 | teacher监督来源 | student学习输出 |
|---|---|---|
| Teacher endpoint/shortcut | teacher完整终点 | 直接复现teacher最终功能 |
| 标准CD | teacher相邻ODE轨迹点 | 不同轨迹点映射到同一数据终点 |
| CTM | teacher相邻ODE轨迹点 | 显式学习任意`t->s`轨迹转换 |

因此：

- teacher endpoint/shortcut最接近fidelity或功能蒸馏；
- 标准CD是“使用轨迹监督的终点一致性蒸馏”；
- CTM是更显式的trajectory mapping distillation；
- 标准CD位于纯终点功能拟合与完整anytime轨迹映射之间。

## 4. 关键实验数据

### 4.1 同规模普通CTM：`4x72-16 -> 4x72-1`

| 方法 | DSM | 成功率 | 覆盖 | 熵 |
|---|---:|---:|---:|---:|
| 残差式CTM | 0 | 103/120，85.8% | 10/24 | 0.359 |
| 残差式CTM | 0.1 | 104/120，86.7% | 12/24 | 0.563 |

DSM改善了4x72的覆盖和熵，但仍远低于16步teacher的`116/120、24/24、0.954`。

### 4.2 同规模Boundary-CTM消融：`4x72-16 -> 4x72-1`

| 方法 | 成功率 | 覆盖 | 熵 |
|---|---:|---:|---:|
| Boundary-CTM uniform | 107/120，89.2% | 12/24 | 0.464 |
| `0->1`采样50% | 101/120，84.2% | 12/24 | 0.611 |
| 加endpoint anchor | 96/120，80.0% | 12/24 | 0.630 |
| 加多噪声距离约束 | 101/120，84.2% | 5/24 | 0.280 |

Boundary提高了一步成功率；强化`0->1`使已有模式更均衡但不增加覆盖；现有欧氏多噪声约束明显失败。

### 4.3 跨规模方法与初始化四格矩阵：`4x72-16 -> 3x48-1`

| 方法 | 初始化 | 成功率 | 覆盖 | 熵 | 最佳epoch |
|---|---|---:|---:|---:|---:|
| 简化EMA endpoint CD | Random | 20/120，16.7% | 7/24 | 0.520 | 499 |
| Boundary-CTM | Random | 25/120，20.8% | 4/24 | 0.313 | 492 |
| 简化EMA endpoint CD | Full-3x48 | 100/120，83.3% | 12/24 | 0.578 | 0 |
| Boundary-CTM | Full-3x48 | 109/120，90.8% | 12/24 | 0.493 | 15 |

结论：

1. 初始化是绝对主效应，Random下两种方法均失败；
2. Full初始化下Boundary-CTM比简化CD成功率高7.5个百分点；
3. Boundary-CTM没有提高覆盖，熵反而低0.085；
4. 最佳checkpoint非常早，能力主要来自Full-3x48初始化，继续优化训练loss会破坏原有分布。

### 4.4 固定Full初始化的endpoint、Flow-CTM与anchor比较

| 方法 | 方法类别 | 最佳epoch | 成功率 | 覆盖 | 熵 |
|---|---|---:|---:|---:|---:|
| 纯teacher endpoint/shortcut | 固定teacher端点功能蒸馏，非严格CD | 272 | 107/120，89.2% | **17/24** | **0.765** |
| 纯Flow-CTM＋DSM（boundary-preconditioned） | 最接近官方CD/CTM | 15 | **109/120，90.8%** | 12/24 | 0.493 |
| Flow-CTM＋endpoint anchor 0.05 | CTM与端点功能蒸馏的联合目标 | 394 | 99/120，82.5% | 9/24 | 0.502 |
| Flow-CTM＋endpoint anchor 0.1 | CTM与端点功能蒸馏的联合目标 | 394 | 103/120，85.8% | 11/24 | 0.482 |

最新结论：

1. 纯Flow-CTM取得最高SR，但明显压缩模式；
2. 纯teacher endpoint少1.6个百分点SR，却多保留5个模式，熵高0.272，是当前最佳SR—多样性折中；
3. 简单线性加入`0.05/0.1` endpoint anchor没有结合两者优势，反而降低SR和覆盖；
4. Flow-CTM最佳checkpoint仅在epoch 15，anchor两组则在epoch 394；继续降低训练目标不等价于保持闭环模式；
5. 这说明问题不是“缺少一点teacher监督”这么简单，而是CTM自举目标和endpoint目标在共享参数上的梯度冲突、checkpoint选择及时间采样需要重新设计。

术语上，纯teacher endpoint/shortcut不能严格称为Consistency Distillation。它直接使用teacher多步终点作为固定标签：

```text
L_endpoint = ||S_one-step(noise,state)-T_multi-step(noise,state)||^2
```

规范CD/CTM则使用teacher相邻ODE推进与EMA student构造自举一致性target。两者都压缩teacher推理步数，但监督机制不同；因此本文将前者称为“端点功能蒸馏”，将后者称为“Flow-CTM/CD”。


### 4.5 为什么简单的endpoint fidelity能保留更多模式

当前结果并不矛盾。Teacher endpoint对每个相同的`state、noise`提供确定的teacher多步终点：

```text
S(noise,state) ~= Phi_T(noise,state)
```

如果不同噪声对应不同绕障路径，这个paired target会直接保存teacher的noise-to-mode对应关系。Flow-CTM主要要求两条时间路径最终自洽，却没有唯一规定它们应落到哪个teacher模式；保留24种模式、压缩到12种模式甚至集中到少数安全模式，都可能成为低一致性loss的解。DSM保证输出仍在专家动作流形附近，但不保证特定噪声与模式之间的耦合。

此外，实际部署只执行`noise,0 -> action,1`。Endpoint fidelity直接优化这一任务；Flow-CTM还需拟合大量任意`t->s`转换，会占用有限`3x48`容量并产生梯度竞争。Full-3x48初始化原本已有多模态结构，endpoint训练更像保留原映射的功能微调，而EMA自举可能逐步重画noise-to-mode分区。Flow-CTM最佳epoch仅为15也支持这一解释。

两组SR只相差2/120，可能属于Standard-120波动；但覆盖`17 vs 12`、熵`0.765 vs 0.493`的差距较大。审慎结论是：当前paired endpoint fidelity比自举trajectory consistency更直接地保护有限容量student中的teacher模式映射，但仍需Standard-480、Paired-1000/JS和多seed验证，不能据此宣称endpoint普遍优于CTM。

### 4.6 多seed Standard-480验证（2026-07-29）

为检验Standard-120中的差异是否来自小样本或单训练seed波动，固定`FM-4x72-16-Full` teacher、`FM-3x48-1` student和Full-3x48 warm start，只改变训练seed并比较纯teacher endpoint与Flow-CTM＋DSM。两种方法均训练500 epochs，按各自验证指标选择最佳EMA checkpoint。

| 方法 | 训练seed | 最佳epoch | 成功率 | 模式覆盖 | 归一化模式熵 |
|---|---:|---:|---:|---:|---:|
| Teacher endpoint/shortcut | 43 | 496 | 440/480，91.7% | 22/24 | 0.828 |
| Teacher endpoint/shortcut | 44 | 346 | 445/480，92.7% | 23/24 | 0.851 |
| Flow-CTM＋DSM | 43 | 391 | 395/480，82.3% | 13/24 | 0.344 |
| Flow-CTM＋DSM | 44 | 218 | 414/480，86.3% | 12/24 | 0.437 |
| **Endpoint两seed均值** | **43/44** | — | **92.2%** | **22.5/24** | **0.839** |
| **Flow-CTM两seed均值** | **43/44** | — | **84.3%** | **12.5/24** | **0.390** |

Endpoint相对Flow-CTM平均提高`7.9`个成功率百分点、多覆盖`10.0`个模式，归一化模式熵提高`0.449`。两个seed的方向完全一致：seed 43分别改善`+9.4`个百分点、`+9`模式和`+0.484`熵；seed 44分别改善`+6.5`个百分点、`+11`模式和`+0.414`熵。

这修正了Standard-120阶段“Flow-CTM成功率略高、endpoint仅多样性更好”的暂时判断。扩大到480条轨迹并更换训练seed后，endpoint在成功率和多样性上均占优；此前`109/120 vs 107/120`的2条成功差异更可能是小样本波动，而覆盖差异反映了更稳定的方法效应。

当前结论限于本项目的Avoiding任务、`3×48`有限容量student和当前实现。Flow-CTM的collapse已经跨seed复现，不能简单归因于随机初始化或偶然漏采低频模式；但在seed 42 Standard-480及三seed Paired-1000/JS完成前，仍不宣称endpoint在其他任务上普遍优于CTM。未完成的Paired计数不写入正式结果。实验根目录为`logs/avoiding/flow_endpoint_vs_ctm_multiseed/`。

#### 与小模型Full和Solver基线的关系

当前实验确实是跨规模、跨步数蒸馏：Teacher为`FM-4x72-16-Full`（274,826参数、16步），Student为`FM-3x48-1`（95,042参数、1步），参数量缩小约`2.9×`，积分步数缩小`16×`。Student不是随机初始化，而是由原始专家数据完整训练的`FM-3x48-16-Full` warm start。

| 模型/方法 | 参数量 | 训练或转换方式 | 推理步数 | Standard-480成功率 | 模式覆盖 | 模式熵 |
|---|---:|---|---:|---:|---:|---:|
| `FM-3x48-16-Full` | 95,042 | 原始专家数据完整训练 | 16 | 445/480，92.7% | 24/24 | 0.965 |
| `FM-3x48-1-Solver` | 95,042 | 同一Full checkpoint直接改成1步，不训练 | 1 | 394/480，82.1% | 14/24 | 0.569 |
| `FM-3x48-1-Endpoint-4x72` | 95,042 | 大Teacher端点蒸馏，三训练seed均值 | 1 | 91.0% | 22.7/24 | 0.837 |
| `FM-3x48-1-FlowCTM-4x72` | 95,042 | 大Teacher Flow-CTM＋DSM，三训练seed均值 | 1 | 84.2% | 12.3/24 | 0.431 |

这四行分别回答不同问题：

1. `FM-3x48-16-Full`是当前小模型在完整训练、16步求解下的参考能力上限，而不是蒸馏模型；
2. `FM-3x48-1-Solver`隔离了纯粹减少积分步数的损失：成功率下降`10.6`个百分点，覆盖由24降至14；
3. Endpoint跨规模蒸馏把成功率恢复到距离Full仅`1.7`个百分点，并把覆盖恢复到平均22.7个模式，说明其学习到了有效的单步shortcut；
4. Endpoint仍未完全恢复Full的分布均衡性，模式熵低`0.128`；因此当前结论是“基本恢复成功率并保留大部分模式”，而不是无损蒸馏；
5. Flow-CTM仅比Solver平均高`2.1`个百分点，却覆盖更少模式且熵更低，说明当前CTM训练并未有效解决单步化引入的mode collapse。

## 5. 统一结论与下一步

1. 当前最接近官方Consistency Distillation的是`Boundary-CTM + DSM`，不是teacher endpoint蒸馏。
2. 当前获得最佳综合结果的是纯teacher endpoint/shortcut；两个新seed的Standard-480均值为`92.2% SR、22.5/24、H=0.839`。
3. Standard-120中Boundary-CTM的微弱SR优势未在新seed的Standard-480复现；相反，Flow-CTM平均SR低`7.9`个百分点，并稳定集中到约12–13个模式。
4. Random初始化不能承接跨规模蒸馏；Full小模型初始化目前不可替代。
5. 简单动作空间欧氏分布约束和固定权重endpoint anchor均无效。
6. 后续优先方向应是：
   - 保存多个epoch，并用SR和模式熵联合选checkpoint；
   - 分阶段训练：先endpoint保持noise-to-mode映射，再小学习率CTM；
   - 使用梯度冲突处理或交替优化，而非直接相加loss；
   - 使用绕障拓扑/轨迹语义约束替代动作欧氏距离；
   - 候选通过Standard-120后再做Standard-480和Paired-1000/JS。
